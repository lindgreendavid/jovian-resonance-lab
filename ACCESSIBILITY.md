# Accessibility contract

The public laboratory will support keyboard operation, visible focus, meaningful landmarks, text
alternatives for every canvas or chart, reduced motion, forced colors, a 320-pixel layout without
page-level horizontal overflow, and controls with at least a 44-pixel target size. Animation state
must also be available as text or a semantic table. The v1 convergence chart has keyboard-operable
step selectors, a live textual value, and a semantic table containing every prespecified gate,
observed value, threshold, and outcome.
